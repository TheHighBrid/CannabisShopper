# CanShop v2.00

CanShop v2.00 is the major visual-system release. It applies the supplied CanShop identity throughout the Android application while preserving the existing craft-flower research workflow.

## Complete interface redesign

- deep forest backgrounds with fresh green and lime highlights
- clean white primary foregrounds and muted sage secondary text
- redesigned main launcher icon, round launcher icon, alternate icon, and splash screen
- unified bag-and-leaf CanShop mark
- consistent headings, body text, numbers, ranking markers, score circles, separators, shadows, and surface hierarchy
- redesigned primary, secondary, ghost, icon, and text buttons
- restyled filters, inputs, selectors, checkboxes, cards, status pills, dialogs, result layouts, and empty states
- reusable in-app icon system for refresh, filter, search, verification, information, navigation, close, and add actions
- responsive mobile layout with branded bottom navigation

## Research workflow preserved

CanShop v2.00 continues to:

- scan the supported Bulk Buddy craft, cannabis, AAAA, indica, hybrid, sativa, pagination, and homepage sources
- verify candidate products from individual product pages
- extract ratings, flavours, THC, CBD, batch dates, package prices, price per gram, and explicit availability
- keep products and preferences in local device storage
- block checkout, unrelated hosts, and external storefront navigation
- retain manual entry as a fallback

## Install

Download `CanShop-v2.00.apk` and verify it with `CanShop-v2.00.apk.sha256`.

The APK is a sideload build signed through the repository's existing GitHub build configuration. CanShop remains a non-transactional research tool for legal-age adults in Canada. Verify prices, availability, freshness, legality, lab information, and local rules independently.
