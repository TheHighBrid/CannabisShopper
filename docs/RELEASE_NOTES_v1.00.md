# CanShop v1.00

The first complete CanShop release turns the original command-line prototype into an installable Android craft-flower research notebook.

## Included

- Android app for API 23 and newer
- Legal-age confirmation
- Live public craft-flower listing refresh with safe manual fallback
- Craft flower only filtering
- Automatic exclusion of kief, hash, pre-rolls, edibles, vapes, extracts, concentrates, and CBD candy
- Discounts ignored in ranking
- Canadian-dollar price-per-gram comparison
- Review, transparency, terpene-fit, availability, and cannabinoid-field signals
- Three-ounce variety versus quarter-pound 15% value guardrail
- Local-only saved products and preferences
- Fictional, visibly labelled sample data
- Repaired TypeScript CLI
- Automated validation, APK build, SHA-256 checksum, and release publishing

## Install

Download `CanShop-v1.00.apk` and verify it against `CanShop-v1.00.apk.sha256`. Android may ask you to allow installation from the app used to open the APK.

## Important

CanShop is a non-transactional research tool for people of legal cannabis age in Canada. It does not sell cannabis, place orders, provide medical advice, or guarantee listing accuracy, product quality, safety, legality, freshness, or availability.

The GitHub APK is a sideload build signed with Android's debug signing configuration. Replace it with private production signing before Play Store distribution.
